# Wallet calendar refinement

## What will change
- Replace the simple Today panel with a compact seven-day calendar strip in the wallet.
- Highlight today clearly and let each date show whether it contains planned items.
- Show the selected day’s agreement-based nanny hours and calendar entries underneath.
- Add clear wording that normal nanny days and hours sync from the nanny agreement, while school dates, activities, notes, cancellations and one-off shifts can be added manually.
- Keep direct actions to open the full calendar and add daily notes.

## Technical details
- Keep the existing shared calendar data and permissions unchanged.
- Implement the interaction only in the wallet interface, with mobile-friendly date buttons and no new database changes.
- Verify the updated wallet at mobile and desktop sizes.
